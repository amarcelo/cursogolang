
## Desafio: API de produtos

Crie uma API que rode na porta `8080` e tenha as seguintes rotas:

### 1. Página inicial

Rota:

```text
GET /
```

Resposta:

```text
API de Produtos Online
```

### 2. Listar todos os produtos

Rota:

```text
GET /products
```

Resposta esperada:

```json
[
  {
    "id": 1,
    "name": "Notebook",
    "price": 3500
  },
  {
    "id": 2,
    "name": "Mouse",
    "price": 80
  }
]
```

### 3. Buscar produto pelo ID

Rota:

```text
GET /products/1
```

A API deve retornar somente o produto com o ID informado.

Caso o produto não exista, deve retornar:

```json
{
  "error": "Produto não encontrado"
}
```

com o status HTTP `404`.

### 4. Validar o método HTTP

As rotas de consulta devem aceitar apenas o método `GET`.

Caso outro método seja utilizado, retorne o status:

```text
405 Method Not Allowed
```

## Requisitos extras

Use:

```go
w.Header().Set("Content-Type", "application/json")
```

para respostas JSON.

Para converter o ID recebido na URL:

```go
idText := strings.TrimPrefix(r.URL.Path, "/products/")
id, err := strconv.Atoi(idText)
```

Para definir um status HTTP:

```go
w.WriteHeader(http.StatusNotFound)
```

O objetivo é completar as três funções sem alterar a estrutura principal do programa.
